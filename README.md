## Proyecto en producción

### Sistema de Evaluaciones — CCLEM

Sistema web institucional desarrollado para gestionar y aplicar evaluaciones en el Centro de Conciliación Laboral del Estado de Morelos.

Permite administrar convocatorias, cuestionarios, categorías y preguntas, participantes, evaluaciones, resultados y reportes. Incluye importación de participantes mediante Excel/CSV, selección aleatoria de preguntas, autoguardado, control de intentos, calificación automática y revisión de respuestas abiertas, así como generación de reportes PDF.

**Tecnologías:** PHP, Laravel, MySQL y JavaScript.

**Estado:** Implementado y operando en producción.

> El código fuente es privado por tratarse de un sistema institucional.
