## Proyectos actuales

Sistema web para administrar clientes, equipos, citas, técnicos, reportes de servicio, cotizaciones, pagos, mantenimientos y notificaciones.

**Tecnologías:** PHP, Laravel, MySQL, JavaScript y Web Push.

Nueva versión de un sistema institucional para registro y administración de turnos, áreas de atención, módulos, llamados y pantalla pública.

**Tecnologías:** PHP, Laravel, MySQL y JavaScript.

### DIGIALZA Legal — SaaS de gestión jurídica
Proyecto en etapa inicial para desarrollar una plataforma SaaS orientada a la gestión de despachos jurídicos.

**Tecnologías:** Laravel, PHP, MySQL y Vue.js.
